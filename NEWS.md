# markitdownshiny 0.0.1

- `check_markitdown_installation()` reports whether Python MarkItDown and the `markitdown` CLI are available.
- `convert_to_markdown()` can now return a structured result with Markdown and metadata, and uses MarkItDown's local-file API.
- `convert_to_markdown()` converts local documents to Markdown using Microsoft's Python MarkItDown package.
- `launch_markitdown_app()` opens a Shiny app with grouped controls, refined typography, a calmer color palette, result status, Markdown and rendered HTML previews, copy-to-clipboard, and `.md` downloads.
